# Open World Mobile

Браузерный 3D-прототип открытого мира, рассчитанный на Android и управление касаниями.

## Запуск
Откройте `index.html` через локальный сервер или разместите проект на статическом хостинге. Для разработки удобно использовать любой сервер с поддержкой ES-модулей.

## Управление
- Левый виртуальный стик — движение.
- Правая часть экрана — поворот камеры.
- Кнопка «Прыжок» — прыжок персонажа.

## Технологии
- Three.js
- JavaScript ES modules
- CSS touch controls

Это стартовый прототип, а не готовая игра уровня GTA 5. Мир, модели, физика, транспорт, NPC и миссии будут добавляться постепенно.
