# Open World Mobile

Мобильный браузерный 3D-прототип открытого города. Проект ориентирован на Android: сенсорное управление, альбомную ориентацию и возможность установки на главный экран как веб-приложение (PWA).

## Технологии
- Three.js — 3D-сцена, камера, материалы и освещение.
- Vite — сборка и локальная разработка.
- JavaScript ES modules — игровая логика.
- PWA manifest + service worker — установка и кэширование оболочки.

## Запуск
1. Установить Node.js.
2. Выполнить `npm install`.
3. Выполнить `npm run dev -- --host 0.0.0.0`.
4. Открыть адрес, который покажет Vite.

Для публикации: `npm run build`. Готовые файлы появятся в `dist/`.

## Управление
- Левый виртуальный стик — движение.
- Проведение пальцем по правой части экрана — поворот камеры и изменение дистанции.
- «Прыжок» — прыжок.
- «Бег» — ускоренное движение.
- На компьютере доступны стрелки, Shift и Space.

## Реализовано в текущем прототипе
- Процедурный городской район с дорогами, тротуарами, зданиями и фасадными окнами.
- Деревья, фонари, небольшой парк и маркер будущего задания.
- Персонаж с простой анимацией ходьбы и прыжком.
- Движущийся городской трафик и гуляющие NPC.
- Камера от третьего лица, мини-карта, внутриигровые часы и сенсорное управление.
- Базовые столкновения со зданиями и границами карты.
